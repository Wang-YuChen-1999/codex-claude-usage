# 品牌圖示

本目錄包含本機應用程式使用的三個原生品牌圖示，供介面識別對應服務：

- `codex-native.ico`：Codex / OpenAI。
- `claude-native.ico`：Claude / Anthropic。
- `antigravity-native.ico`、`antigravity-native.png`：Antigravity / Google，同一圖示的兩種格式。

相關品牌圖示及商標權利由各權利人保留；本專案的程式碼授權不代表對第三方品牌資產授予額外權利，也不表示上述公司背書本專案。再散佈或另作他用前，請自行確認適用的品牌使用規範。

程式優先讀取本機已安裝應用程式的圖示，這些檔案作為內嵌後備資產。
